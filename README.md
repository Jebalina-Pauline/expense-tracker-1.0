# Expense tracker

A private expense tracker for iPhone. There's no account and no server. Everything you enter is stored only on your phone.

## Put it on GitHub Pages (one time)

1. Sign in to github.com, then click **New repository**. Name it `expense-tracker` and set it to **Public**, which the free plan needs for Pages. The code holds none of your data.
2. On the new repository, click **uploading an existing file**. Drag in **everything inside this folder**, including the `icons` and `screens` folders, then click **Commit changes**.
3. Go to **Settings → Pages**. Under "Build and deployment", choose **Deploy from a branch**, pick **main** and **/ (root)**, then click **Save**.
4. After a minute or two the page shows your link: `https://YOUR-NAME.github.io/expense-tracker/`

## Install on your iPhone

1. Open the link in **Safari** while you have internet.
2. Tap **Share → Add to Home Screen → Add**.
3. Open **Expenses** from your Home Screen. From now on it works offline too.
4. In **Profile**:
   - **App lock**: set your 4-digit PIN.
   - **Device notifications → Allow**: lets reminders show.
   - **Export data → Add due dates to Calendar**: tap **Add All** to get bill reminders even when the app is closed.

## Keep your data safe

- Your data lives only in this app on this phone. If you delete the app, the data is deleted with it.
- Tap **Profile → Export data → Back up data** now and then, and save the file to **iCloud Drive** or **Files**.
- To move to a new phone, or after "Forgot PIN → Erase data", use **Restore from backup**.
- **Never upload backup files to GitHub.** GitHub only holds the app's code.

## Updating the app later

Upload the new files over the old ones in the repository. Your phone picks up the update the next time it opens the app with internet, and your data stays as it is.
